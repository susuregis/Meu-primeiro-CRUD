# 📦 CRUD com JavaScript + MongoDB

Este projeto é uma aplicação **CRUD** (Create, Read, Update, Delete) desenvolvida com **JavaScript** e conectada a um banco de dados **MongoDB**. Foi criado com o objetivo de praticar a manipulação de dados, integração com banco de dados e funcionalidades básicas de um sistema completo.

---

## 💡 Funcionalidades

- ✅ Criar novos registros
- 🔍 Listar todos os registros salvos no banco
- ✏️ Editar registros existentes
- ❌ Excluir registros do banco
- 💾 Integração com **MongoDB** para persistência dos dados

---

## 🛠️ Tecnologias utilizadas

- **JavaScript (Node.js)**
- **Express.js** (framework para rotas e servidor)
- **MongoDB** (banco de dados NoSQL)
- **Mongoose** (ORM para MongoDB)
- **HTML + CSS** (interface básica)
